# BranchQuest - Group Project Template

Collaborative semester project: a choice-driven Python text adventure.

## Quick start

1. Clone repository.
2. Create your feature branch.
3. Implement one scoped change.
4. Open pull request to `main`.

## Folder structure

- `src/main.py`: game entry point
- `src/engine.py`: routing and game loop helpers
- `src/scenes/`: scene modules
- `src/data/`: JSON or text game data
- `tests/`: manual and scripted test artifacts
- `docs/`: design docs and meeting notes

## Team process

- Use small pull requests.
- Reference milestone/week in PR title.
- Include test notes in PR description.
