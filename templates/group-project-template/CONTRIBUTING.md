# Contributing Guide

## Branch naming

Use: `feature/<short-description>` or `fix/<short-description>`.

## Pull request checklist

- [ ] Change is scoped and focused.
- [ ] Code runs locally.
- [ ] Relevant scene/test checklist updated.
- [ ] PR description explains what changed and why.

## Review expectations

- At least one teammate review before merge.
- Resolve comments before merge.
