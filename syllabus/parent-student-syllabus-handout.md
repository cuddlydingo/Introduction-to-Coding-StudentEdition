# Introduction to Coding (Python) - Parent/Student Syllabus Handout

## Course snapshot

- **Course length:** 18 weeks (1 hour in-person each week)
- **Primary language:** Python 3
- **Who this is for:** Beginners with no prior coding experience
- **Instructor model:** In-person lesson + weekly take-home practice

## Course purpose

This course helps students build real coding fundamentals. Students will learn how to read, write, test, and explain small Python programs. The class emphasizes clear thinking, persistence, and problem-solving over memorization.

By the end of the semester, students should be able to build small command-line programs independently and explain how their code works.

## What students will learn

Students will practice:

- Variables, data types, and expressions
- Conditionals (`if/elif/else`)
- Loops (`for` and `while`)
- Functions and modular code
- Lists, dictionaries, and strings
- Debugging and error reading
- Basic algorithms (search and sort)
- File input/output
- Introductory code comparison across Python, Lua, C++, and Java

## Materials and platforms

Students may use:

- Local Python installation with an editor (recommended)
- Browser-based coding environments when needed
- Course resources (Udemy, Learn Python the Hard Way, teacher handouts)
- GitHub for assignment submissions and revision tracking

## Weekly structure

Each in-person class (60 minutes) is structured as:

1. Warm-up and review
2. New concept mini-lesson
3. Guided practice
4. Assignment launch and Q&A

Students are expected to complete homework between sessions.

## Homework and submission expectations

Weekly homework follows one connected story, **BranchQuest**, in which students help build a class text adventure and, by the final weeks, ship a game of their own. Each week is submitted on its own **quest branch** through a merge request, giving students a gentle first taste of professional version-control habits.

- One homework assignment per week
- Submissions through GitHub before the next class
- Students should commit work progressively (not one final upload only)
- Students may be asked to explain their code briefly in class

## Major course components

- **Weekly coding homework (individual)**
- **Collaborative class game project:**
  A Python text-based "choose your adventure" game built in small teams
- **Final individual coding project**
- **One research paper on a technology topic**

## Research paper overview

Students will complete one paper (minimum 1,024 words) with milestone checkpoints throughout the semester:

- topic proposal
- bibliography
- thesis and outline
- draft
- final paper + short presentation

## Academic integrity and AI policy

This course is designed to develop authentic student coding ability. Therefore:

- **AI-generated code/content is not allowed for homework or projects.**
- Students must be able to explain submitted work.
- Commit history and in-class code walkthroughs will be used to verify authorship.

Students sign the [Academic Honor Statement](academic-honor-statement.md) in Week 1 to acknowledge these expectations.

If a student cannot explain submitted work, the assignment may be reassessed in class.

## Family support recommendations

Parents/guardians can help by:

- encouraging a consistent weekly homework routine
- asking students to explain what they built
- celebrating progress, persistence, and debugging effort
- ensuring students submit work on time through GitHub

## Suggested grading categories

- Weekly homework: 40%
- Collaborative game project: 25%
- Final individual project: 20%
- Research paper: 10%
- Participation/professional habits: 5%

## Communication and help

Students should bring questions to class each week. Debugging confusion is normal in coding; asking clear questions is part of learning.

Parents/guardians are encouraged to contact the instructor with concerns about pacing, workload, or support needs.
