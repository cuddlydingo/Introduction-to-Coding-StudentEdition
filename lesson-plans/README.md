# Introduction to Coding - Instructional Package

This folder contains a complete semester-ready package aligned to
[Introduction_to_Coding.md](../Introduction_to_Coding.md).

## Files in this folder

- [weekly-lesson-plans.md](./weekly-lesson-plans.md):
  Detailed week-by-week in-class plan and individual homework assignments.
- Includes an optional Week 16 bonus extension for Python API/JSON integration
  using public endpoints and `requests`.
- [github-workflow-and-submission.md](./github-workflow-and-submission.md):
  Student submission workflow for GitHub and instructor grading workflow.
- [collaborative-game-project.md](./collaborative-game-project.md):
  Semester-long collaborative "choose your adventure" Python game project.
- [research-paper-track.md](./research-paper-track.md):
  One-paper research assignment integrated across the semester.
- [grading-and-academic-integrity.md](./grading-and-academic-integrity.md):
  Suggested grading weights, rubrics, and AI-use policy implementation.

## Suggested weekly rhythm (1-hour in-person model)

Each class meeting can follow a consistent pattern:

1. **5 min** - Attendance, quick warm-up prompt, and homework pulse check.
2. **10 min** - Error clinic from prior homework (student-led debugging).
3. **20 min** - New concept mini-lesson.
4. **15 min** - Paired coding or guided practice.
5. **10 min** - Exit ticket, assignment launch, and GitHub reminder.

## Notes

- The package assumes students complete coding practice between sessions.
- The group game and research paper are intentionally scaffolded so they do not
  overwhelm weekly coding practice.
- Weekly homework follows the semester-long **BranchQuest** story arc; a
  student-facing overview (cast, per-week beats, git "quest branch" flow) is in
  [../course-materials/branchquest-map.md](../course-materials/branchquest-map.md).
- AI-generated solutions are prohibited for student submissions.
