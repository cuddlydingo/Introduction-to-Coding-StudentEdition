## Instructor usage

- Share this folder with students in the main class repository.
- For Week 8 and Week 15, students should copy source files into their weekly assignment folders before editing.
- For the Week 16 bonus extension, students may use `week16-api-bonus/` to practice JSON/API integration with Python `requests`.
- These artifacts are part of the **BranchQuest** story: the Week 8 buggy files are the Glitch's attack that Grace helps students fix, and `week15-file-inputs/missions.txt` is the game's mission log. See [branchquest-map.md](branchquest-map.md).
