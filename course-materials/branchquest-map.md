# BranchQuest — Your Semester Map

Welcome, apprentice! This one-pager is your map for the whole semester. Keep it
handy so you always know where you are in the story and what you are building.

## The story

You are the newest **apprentice** at the **Maker's Guild**, a workshop where
coders ("makers") build games. Together the Guild is building a choose-your-path
text adventure called **BranchQuest**. Each week you take on a **quest** that
teaches a new coding skill and adds a piece to the game. By the end, you ship a
game of your very own.

**Your apprentice name is the GitHub username you pick in Week 1.** Use it all
semester — in your code, your commits, and your quests.

## Who you'll meet

- **Ada** — the Guildmaster. She hands out each week's quest and always asks,
  "What are we really trying to build?"
- **Grace** — the Chief Bug-Hunter. She teaches you to squash bugs and test your
  work. (The real Grace Hopper helped make "bug" a computer word!)
- **Your party:** **Aria** (archer), **Dax** (healer), **Lina** (mage),
  **Timo** (scout), and **Nova** (knight, who joins in Week 11).
- **The Glitch** — a sneaky swarm of bugs that corrupts the game when code gets
  messy. Watch out for it in Week 8!

## How you turn in a quest

Each week is a **quest branch**. The pattern is always the same:

1. Start from an up-to-date `main`.
2. Make this week's branch: `git checkout -b quest/weekNN-topic`.
3. Do the quest in the listed files.
4. Commit, push, and open a **merge request** (also called a pull request).
5. Get feedback, then merge it in before the next class.

## The journey (what you build each week)

| Week | Your quest |
| ---- | ---------- |
| 1 | Join the Guild: welcome banner, apprentice badge, goals |
| 2 | Meet the party and build hero profiles |
| 3 | Build the game's score and resource math |
| 4 | Build the branching **gates** (choices) |
| 5 | Train the party with loops |
| 6 | Forge reusable tools (functions) |
| 7 | Build the inventory and message systems |
| 8 | Fight the Glitch: hunt and fix bugs |
| 9 | Ship **Cave Quest**, the first playable chapter |
| 10 | Clean up (refactor) the game before it grows |
| 11 | Build the party roster; **Nova joins** |
| 12 | Design the quest-select screen (plan first!) |
| 13 | Build search so heroes find items fast |
| 14 | Build the leaderboard (sorting) |
| 15 | Save and load the game (files) |
| 16 | Explore other coding "dialects" (Lua, C++, Java) |
| 17 | Plan and build **your own** game |
| 18 | The Guild Showcase: present your game |

## Every quest ends with a "Level up"

At the bottom of each week's packet you'll find an optional **Level up**:

- a **side-quest** if you want a challenge,
- a **hint** if you get stuck, and
- a **self-check** to run before you submit.

Have fun, and welcome to the Guild!
