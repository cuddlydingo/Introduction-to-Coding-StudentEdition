# API Side-Project Ideas (Bonus)

Use one API and build a small script that prints meaningful output.

## Project prompts

1. Space photo spotlight (NASA): print today's image title and URL. Bonus: save
  the image URL history for 7 days.

1. Pokemon stat scout (PokeAPI): ask for a Pokemon name and print type, height,
  weight, and first 3 moves.

1. Launch watch (SpaceX): print the latest launch name, date, and success
  status.

1. Character search (Rick and Morty): ask for a character name and print all
  matches on page 1.

1. Movie trend digest (TMDB): print top 5 trending movie titles.

1. Weather snapshot (OpenWeatherMap): ask for a city and print temperature,
  humidity, and conditions.

1. Country profile card (REST Countries): ask for a country name and print
  capital, currencies, and languages.

## Submission checklist

- Include script source code.
- Include one sample output run.
- Include a short reflection:
  - What endpoint did you use?
  - Which JSON fields were most useful?
  - How did you handle errors?
