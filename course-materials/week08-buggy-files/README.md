# Week 08 Buggy Starter Scripts

Use these files for Week 8 debugging practice.

## Homework-required files

- `week08_p1_name_error.py`
- `week08_p2_type_error.py`
- `week08_p3_index_error.py`

## Extra in-class practice files

- `week08_p4_value_error.py`

## Workflow

1. Copy files into your assignment folder.
2. Run each script.
3. Read traceback/error behavior.
4. Fix and save corrected versions.
5. Document fixes in your debug log.
